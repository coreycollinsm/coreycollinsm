# The CCM Platform

The CCM platform is a modular full-stack system consisting of:

Frontend applications built with **Next.js** and a backend API built with **Node.js / Express**.

### Repositories

**ccm-site**  
Next.js portfolio frontend for **coreycollinsm.com**

Features:

- Project portfolio
- Contact form with spam protection
- Custom analytics instrumentation
- UTM attribution tracking
- Button interaction tracking
- Resume download tracking

<br>

[Link to Repo](https://github.com/coreycollinsm/ccm-site)

<br>

**ccm-portal**  
Next.js portal application for **portal.coreycollinsm.com**

Purpose:

- Secure admin interface
- Data visibility and analytics tools
- Future operational dashboards

<br>

[Link to Repo](https://github.com/coreycollinsm/ccm-portal)

<br>

**ccm-api**  
Node.js / Express backend powering the platform.

Core API routes include:

- GET /health
- POST /contact
- POST /tracking/website-visit
- POST /tracking/button-click

Features:

- AI-assisted spam filtering (Google Gemini)
- MongoDB blacklist validation
- Asana workflow automation
- Custom analytics event ingestion
- Visit attribution tracking
- Anonymous session ID generation

The API is deployed in production and currently supports the live portfolio site.

<br>

[Link to Repo](https://github.com/coreycollinsm/ccm-api)
