# How I Operate

**I build the business system, then I build the software for it.** Most operations leaders hand a process to an engineering team and hope it survives translation. Most engineers get handed a spec and never see the operation it came from. Doing both means the handoff never happens — the sold-to-delivered process and the tool that enforces it get designed as one thing.

**Process that survives turnover.** A repeatable sold-to-delivered handoff, instrumented so it is measured rather than assumed, and documented so execution does not depend on who is in the room.

**Governance without ceremony.** KPI models, service level agreements, and cross-department frameworks that exist to make delivery visible, not to generate status meetings.

**Selection is a leadership decision, not an IT one.** Work management, CRM, and OMS platforms get chosen, configured, and adopted — adoption being the part that actually determines whether the investment returns anything.
